# clawd-tg-bot

[English](README.md) · Русский

Telegram-бот для управления Claude Code на своём компьютере с телефона. ты пишешь сообщение, Claude работает в папке на этом компьютере и присылает ответ в чат.

бот запускает установленный у тебя `claude` CLI от твоего пользователя. твои настройки, правила разрешений и файлы `CLAUDE.md` работают так же, как в терминале.

## возможности

- сессии для каждого чата: новая сессия, продолжение одной из недавних (включая начатые в терминале), смена папки;
- запросы разрешений кнопками: разрешить один раз, отказать или разрешить до конца сессии;
- вопросы Claude кнопками, можно ответить и текстом;
- сообщение с ходом работы, в нём видно вызовы инструментов;
- присланные фото и файлы бот кладёт в папку inbox и передаёт Claude путь;
- Claude может отправить в чат файлы и картинки;
- переключение модели, уровня рассуждений и режима разрешений;
- `/status` с заполнением контекста и лимитами подписки;
- очередь сообщений, пока Claude занят.

## что нужно

- Linux с systemd (пользовательские юниты);
- Python 3 с `venv` (проверено на 3.14);
- установленный Claude Code с выполненным входом (`claude` в `PATH`);
- аккаунт Telegram. бота в [@BotFather](https://t.me/BotFather) поможет создать мастер настройки.

## установка

```sh
git clone https://github.com/chuh420/clawd-tg-bot
cd clawd-tg-bot
./install.sh
```

`install.sh` создаёт `.venv`, ставит зависимости, пишет пользовательский юнит systemd, кладёт ссылку на команду `clawd-tg-bot` в `~/.local/bin` и запускает настройку. если перенесёшь репозиторий, запусти его снова.

## настройка

мастер задаёт несколько вопросов и сам пишет конфиг:

1. находит `claude` и проверяет вход. если входа нет, предлагает запустить `claude auth login`;
2. просит токен от @BotFather и проверяет его в Telegram. если Telegram недоступен, спрашивает прокси;
3. просит написать новому боту любое сообщение, берёт из него твой user id и просит подтвердить;
4. спрашивает стартовую папку, сохраняет конфиг и предлагает запустить бота.

`clawd-tg-bot setup` можно запустить снова в любой момент: сменить токен, добавить аккаунт или выбрать другую папку. Enter оставляет текущее значение.

## конфиг

мастер пишет `~/.config/clawd-tg-bot/env`. открыть его вручную можно командой `clawd-tg-bot config`:

| переменная | значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `ALLOWED_USER_IDS` | id пользователей Telegram, которым доступен бот, через запятую |
| `DEFAULT_CWD` | стартовая папка новых чатов, по умолчанию `~` |
| `CLAUDE_PATH` | путь к `claude`, если его нет в `PATH` |
| `TELEGRAM_PROXY` | прокси, например `socks5://127.0.0.1:1080` |
| `LOG_LEVEL` | по умолчанию `INFO` |

## запуск

```sh
clawd-tg-bot setup     # первая настройка или изменения
clawd-tg-bot on        # запустить
clawd-tg-bot off       # остановить
clawd-tg-bot status    # active / inactive / failed
clawd-tg-bot logs      # смотреть лог
clawd-tg-bot restart   # после правки конфига или кода
clawd-tg-bot config    # открыть конфиг
```

в юните нет секции `[Install]`, поэтому при загрузке бот сам не стартует. ты запускаешь его, когда нужно. `/off` в чате останавливает бота, а снова запустить его можно только из консоли компьютера.

## команды

| команда | действие |
| --- | --- |
| `/new` | новая сессия в текущей папке |
| `/resume` | выбрать одну из 8 последних сессий в текущей папке |
| `/cd путь` | сменить папку и начать новую сессию |
| `/mode` | режим разрешений: default, acceptEdits, plan, bypassPermissions |
| `/model` | сменить модель |
| `/effort` | уровень рассуждений: low, medium, high, xhigh, max, default |
| `/stop` | прервать текущий ход и очистить очередь |
| `/status` | папка, сессия, режим, модель, контекст, лимиты |
| `/off` | выключить бота |

если 10 минут не отвечать на запрос разрешения, бот считает это отказом.

## безопасность

любой из `ALLOWED_USER_IDS` может выполнять команды на твоём компьютере с правами твоего пользователя. оставь в списке только свои аккаунты и никому не показывай токен. бот отвечает только этим id, остальных отправителей пишет в лог.

в режиме `bypassPermissions` кнопок подтверждения нет. включай его только в папках, где ты готов отпустить Claude Code работать без присмотра.

## файлы

- конфиг: `~/.config/clawd-tg-bot/env`;
- состояние чатов (папка, сессия, режим, модель): `~/.local/state/clawd-tg-bot/state.json`;
- полученные файлы: `~/.local/state/clawd-tg-bot/inbox/`.

## репозиторий

- `clawd_tg_bot.py`: сам бот;
- `setup_wizard.py`: мастер настройки, его запускает `clawd-tg-bot setup`;
- `install.sh`: venv, юнит systemd, ссылка на команду, затем настройка;
- `deploy/`: команда `clawd-tg-bot`, шаблон юнита и шаблон конфига.

## примечания

лимиты подписки `/status` берёт из недокументированного эндпоинта с OAuth-токеном, который Claude Code хранит в `~/.claude/.credentials.json`. если эндпоинт изменится, в строке лимитов появится "unavailable", остальное продолжит работать.

проект никак не связан с Anthropic.
